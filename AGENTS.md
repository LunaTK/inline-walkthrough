# Commit message convention

When generating a Git commit message, follow these rules:

- Use Conventional Commits format (e.g., feat:, fix:, refactor:, chore:, docs:).
  - If it does not change code behavior, use refactor.
  - If it fixes broken behavior, use fix.
- Use english for variable names or technical terms.
- Write the commit message in Korean.
- Keep the title under 50-60 characters.
- Be concise and do not restate the diff line by line.
- Strictly distinguish refactor from feat. If it is code relocation or reorganization, use 'refactor:'
